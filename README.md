# GrassSTATory v23.3.0

Concept-parity refinement built on the proven match/state/statistics engine.

## Focus of this release
- Approved premium visual direction carried into the working app.
- Brighter layered navy/teal surfaces and photographic stadium imagery.
- Home / Away Kit Studio with front, 3/4 and back views.
- Compact squad, starting XI, bench and live-event tiles.
- Sequential Goal flow: Scorer -> existing goal type -> Assist / No Assist.
- Opponent identity preview persists into matches.
- First-goal and milestone Moments use the saved player identity.
- Recent Results on Home.
- Player Stats uses medium portrait cards in a swipe/drag carousel.

Upload all files directly to the GitHub repository root. Matching files can be overwritten.
